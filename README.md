# Digital Theme Store - Next.js E-Commerce Application

A modern, high-converting e-commerce product catalog and direct WhatsApp revenue system built with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS**.

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm start
```

---

## 🌟 Key Features

- **16 Curated A4 Product Templates**: Complete dataset with ratings, reviews, specifications, and variants across 4 categories:
  - ⚡ *Action Cameras & Audio*
  - 🛡️ *Security & Body Cams*
  - 🎮 *Drones & Smart Gadgets*
  - 💎 *Fashion & Luxury*
- **Interactive Hero Banner Slider**: Auto-play peek slider with touch swipe for mobile and mouse drag support.
- **Live Search & Category Filtering**: Instant multi-field client-side search across name, category, specs, and price.
- **Global Cart Context with LocalStorage**: Persistent cart with slide-over drawer, quantity controls, and subtotal calculation.
- **1-Click WhatsApp Ordering (+91 89288 84526)**:
  - Formatted invoice checkout for single products.
  - Multi-item cart breakdown.
  - 1-on-1 Growth Consultation booking.
- **Dual Routing**: Supports both `/buy?id=...` and clean dynamic SEO routes `/product/[id]`.
- **Ultra-Responsive UI**: Mobile-first design with floating checkout bars, badges, and smooth animations.
